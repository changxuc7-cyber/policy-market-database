# 政策与市场事件数据库可视化平台

这是一个纯前端、零依赖的可视化平台原型，可直接双击 `index.html` 打开。

## 已实现
- 仪表盘
- 全局搜索
- 政策库与筛选
- 政策详情弹窗
- 市场反应
- 履约节点看板
- 重要市场节点时间线
- 关键参数数据库
- 数据源状态
- 模拟同步更新

## 文件结构
- `index.html`：页面结构
- `style.css`：界面样式
- `data.js`：演示数据
- `app.js`：交互逻辑
